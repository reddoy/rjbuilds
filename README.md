# itsrjbuilds

RJ’s personal site: computers, cars, building apps, and marketing.

React, TypeScript, Vite, and Motion. The introduction types `itsrj` and assembles `builds` from metal letters. Sections cover RJ, apps, marketing, music, movies, and contact. Fun facts cover computers and cars. Press the backtick key for the terminal.

## Development

Use Node 22 or newer.

```sh
npm install
npm run dev
npm run build
```

Content lives in `src/data.ts` and `src/sections/`.
Pushes to `main` build and deploy through `.github/workflows/deploy.yml`.
